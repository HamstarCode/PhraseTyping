# PhraseTyping

AIを活用した英語フレーズ学習タイピングアプリ。

## 概要

PhraseTypingは、実際の場面で使われる自然な英語表現を、
タイピング練習を通して身につけるWebアプリです。

ユーザーが学習したいシチュエーションを入力すると、
AIがその場面に適した英会話を生成します。

生成された英文をタイピングすることで、
実際に使われるフレーズを自然に覚えることを目指します。

## Features

- AIによるシチュエーション別英会話生成
- 英文タイピング練習
- タイピング速度・正確性の計測
- 学習フレーズの保存（予定）
